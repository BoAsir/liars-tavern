# 丢番茄与快捷语(动物叫声说话)设计(2026-10-08 用户追加)

> 用户原话:「先加一个丢番茄的功能吧,还有说话的功能,不同动物有不同的声音,说话的声音就是对应动物的叫声」。
> 用户已定:丢番茄谁都能随时丢;说话只用快捷语(不打字);叫声程序合成(和现有音效一样不加音频文件)。

## 1. 玩法

### 1.1 丢番茄
- 谁能丢:等待厅和牌局里所有在房间的人,包括在场的、出局的和观战的;骗子酒馆和德州都能用。
- 丢给谁:任意一位**有酒客的**玩家(不能丢自己;观战者没有酒客,不能被丢)。
- 冷却:每人 3 秒(`Banter.TOMATO_COOLDOWN`),房主为准;本机按钮或提示显示冷却。
- 纯搞笑,不影响胜负、不打断回合、不影响计时。
- 表现:
  - 丢的人有酒客时右手做一个抛的动作,番茄从手里飞出;没有酒客(观战)时从吧台方向的一个固定点飞来。
  - 番茄沿抛物线飞约 0.6 秒,落点是目标头部附近(按种子随机偏一点:脸、帽子、肩膀)。
  - 命中:「啪叽」声、红色汁水溅开(少量粒子)、一块番茄泥贴在命中处约 6 秒后淡出;同一个头最多叠 3 块,最旧的先没。
  - 被砸的人:吓一跳(`startle`)加抹脸或嫌弃的表情;出局的酒客也会被砸(泥贴在歪着的头上,不做反应)。

### 1.2 快捷语
- 8 句预设(编号 0–7,协议里只传编号):
  - 0「你骗人!」
  - 1「我信你。」
  - 2「这把稳了~」
  - 3「救命啊!」
  - 4「哈哈哈哈!」
  - 5「快点啦…」
  - 6「好牌!」
  - 7「呜呜呜…」
  - 文案可在实现时微调,两种玩法都要说得通。
- 说话频率:每人至少隔 1.5 秒(`Banter.SAY_COOLDOWN`),房主为准。
- 表现:
  - 说话人的头顶冒出对话气泡,文字跟着声音一个字一个字出现,说完停 2.5 秒后淡出。
  - 说话时头随每个音节轻点一下。
  - 声音从说话人的头部位置发出(3D 定位)。

## 2. 操作

- **T 键或鼠标右键**:丢番茄,目标是屏幕上离鼠标光标最近的酒客头部(投影距离 ≤140 px,不含自己);
  没有合格目标时提示「把光标移到要砸的人身上」。
- **Q 键**:打开快捷语面板,显示 8 句带编号的话。
  - 面板打开时按 1–8 或点击说出,Q 或 Esc 关闭;面板打开时数字键只给面板用,不再选牌或下注。
  - 说完自动关上。
- 这几个键都不在现有占用里:1–5、回车、C、空格、F、R、↑↓、WASD、说明书快捷键、Esc。
- 说明书和桌面提示补上「T 丢番茄 · Q 快捷语」。

## 3. 网络

- 不新增 autoload(不改 project.godot):`NetworkManager._ready()` 里加一个子节点 `Banter`(`src/net/banter_net.gd`),
  所有端路径一致为 /root/Net/Banter,RPC 都放在它身上,不影响 NetworkManager 的 RPC 表(`test_net_rpc_order` 不变)。
- 消息(都走 reliable):
  - `rpc_tomato(target_pid)`:客户端 → 房主。房主校验:发送者在名单里、目标在名单里且有酒客、不是自己、过了冷却;
    通过后生成种子,向全员(含房主本机)广播 `rpc_tomato_thrown(from_pid, target_pid, seed)`。
  - `rpc_say(phrase_id)`:客户端 → 房主。校验:0 ≤ id < 8、过了冷却;广播 `rpc_said(pid, phrase_id)`。
  - 房主本机操作直接走同一套校验和广播。不合法的消息静默丢弃(必要时 push_warning)。
- 协议号仍是 v5:0.7.0 尚未发布,和德州共用 v5;德州分支合并时会在 network_manager.gd 的 `_ready` 附近有一处小冲突。
- 等待厅和牌局都可用;回到等待厅、离开房间时清掉冷却记录。

## 4. 叫声合成(动森式「动物话」)

- 新文件 `src/audio/animal_voice.gd`(class AnimalVoice):按物种参数合成一个音节,把一句话逐字拼起来,得到一个 AudioStreamWAV。
  - 每个字(汉字、字母、数字)一个音节,约 70–95 ms;标点是短停顿;「!」末尾音量和音高抬起,「?」句尾上扬,「…」拖长、音高下沉。
  - 音高:物种基准音高 × 按字的哈希给的小起伏(同一句话每次念起来一样)× 本人一点随机偏移(按 pid 定,同一物种的两个人略有不同)。
  - 合成结果按 (物种, 句子编号, 音高偏移档) 缓存;启动后空闲时预热。
- 8 种叫声的合成思路(实现时可调,目标是一听就分得出来,卡通、不刺耳):

  | 物种 | 叫声 |
  |---|---|
  | 狐狸 | 高音短促的「嘤/呀」:带一点噪声的上滑锯齿波,共振峰偏高 |
  | 熊 | 低沉的「呜噢」:低频方波加次谐波,慢起慢收,带一点喉音颤 |
  | 猪 | 「哼哼」:鼻音,低中频脉冲串,每个音节两下快速的喉部脉冲 |
  | 猫 | 「喵」:元音从 i 滑到 a 再到 u 的共振峰滑动,中高音 |
  | 乌龟 | 慢吞吞的「咕噜」:很低的正弦加轻微气泡调制,音节拉长到约 1.4 倍 |
  | 羊驼 | 「嗯~」:哼鸣,带鼻腔共振的正弦加颤音,音高中等偏高 |
  | 猴子 | 「呜哇/吱」:快速上下滑的高音,音节短,偶尔夹一个更高的「吱」 |
  | 鳄鱼 | 低沉的「嘶咕」:噪声嘶声开头,接很低的咕噜,带一点颗粒感 |

- 播放:AudioStreamPlayer3D 挂在说话人头部,走 SFX 总线,遵守 `Sfx.muted`;无头运行时不出声但流程照走(测试可用)。

## 5. 世界与界面

- 世界(TableWorld 或新的 `src/world/banter_fx.gd`):`throw_tomato(from_pid, target_pid, seed)`、`say(pid, phrase_id)`。
  - 番茄、番茄泥网格用 MeshForge 缓存(番茄:红色扁球、绿色蒂;泥:不规则扁片),材质用 WorldMaterials 现有的道具材质;
    小件不投影;番茄泥挂在目标的 Head 下,用完释放。
  - 番茄泥不能让静止状态下的酒客可见网格超过 16 个(只在命中后的几秒内存在,测试按静止状态测)。
  - 汁水粒子复用现有粒子材质;一次 ≤24 粒。
- 酒客:`Patron.hit_by_tomato(local_point)` 触发反应;说话的点头放在 PatronAntics 里(`talk(syllable_times)`)。
- 气泡:用现有的 WorldLabels(名牌挂点那一套)挂在头顶名牌之上,UiTheme 风格的圆角气泡;
  同一个人新说一句就替换旧气泡;不挡自己的手牌(气泡高于名牌,本机自己的气泡可以略小)。
- 音效:Sfx 加「tomato_throw」(短 whoosh)与「tomato_splat」(湿的啪叽:低频冲击加滤波噪声的湿尾巴)。

## 6. 约束

- 不改 project.godot、不改协议号;不在 src/ 里运行时读网格数组;不 duplicate ShaderMaterial;新静态缓存在 main.gd `_exit_tree` 释放。
- 性能:同时飞 8 个番茄、贴 8 块泥时 seat 视角 draw call 增量 ≤ 30,帧时间无明显变化;perf_probe 预算照过。
- 联机冒烟 `tools/lan_smoke.sh` 照过;可选:冒烟里加一次互丢番茄和说话,核对各端都收到。

## 7. 测试

- 协议与校验(无头):冷却、非法 id、丢自己、丢观战者、发送者不在名单,都被房主拒绝;合法的广播给全员且种子一致。
- 叫声:同一 (物种, 句子, 偏移) 两次合成逐样本相同;8 个物种的基频或频谱质心互不相同;「!」和「?」句尾的音高变化方向正确;
  每句时长在 0.4–2.5 秒之间。
- 世界:番茄落点在目标头附近;命中后泥挂在目标 Head 下、6 秒后释放;同一个头最多 3 块;出局的酒客被砸不报错。
- 界面:Q 面板打开时数字键不再选牌或下注;T 选目标的屏幕投影规则;冷却期间不发消息。

### 8.3 操作

- **T 或鼠标右键**:丢番茄,目标是屏幕上离光标最近的酒客头(`head_position()` 投影,≤140 px;不含自己、藏起来的酒客、镜头背后的)。
  没有目标时提示「把光标移到要砸的人身上」;冷却中再按,左侧番茄圆牌抖一下、描边闪红,不发消息。
- **Q**:开 / 关快捷语面板(屏幕左侧居中,在两枚圆牌右边)。面板开着时 1–8(主键盘或小键盘)或点按钮说出,说完自动关上;
  Q / Esc 关面板。面板在 `_input` 里先拦下 1–8、Q、Esc,牌桌的 `_unhandled_input`(选牌 1–5、德州下注预设 1–5、Esc 离开确认)收不到;
  其余按键(9、C、空格……)照常给牌桌。说明书、确认框开着或输入框有焦点时 T / Q 都不响应,圆牌层也藏起。
- 左侧两枚小圆牌:番茄(T)和对话框(Q),冷却时盖一块按剩余比例缩小的暗影扇形并写剩余秒数;点 Q 圆牌也能开面板。
- 提示:骗子酒馆牌桌的待机提示加「T 丢番茄 · Q 快捷语」;两本说明书「操作」章各加两行键位和一条说明。
  德州的下注提示只在轮到自己时显示,而且已经很长,没有加(圆牌上写着键)。

### 8.4 网络与校验

- 房主校验:发送者在等待厅名单里;番茄目标是 int、不是自己、在「有酒客的人」里——对局中是会话的 `seats_with_patrons()`
  (骗子酒馆出局的人还在,德州等下一手才登场的新人不在),等待厅里是已分到形象的成员;快捷语编号是 0–7 的 int;冷却按人算
  (番茄 3 s、快捷语 1.5 s,两者独立)。通过后种子 `randi_range(0, 2^31-1)`,房主本机直接发信号,其余成员逐个 `_send_to`。
- 客户端:本机也有一份冷却(按下就开始,圆牌显示用),冷却中不发消息;收到广播再校验一遍类型 / 范围,握手中(包括对局中入座
  等牌局信息)不处理。`joined_lobby` / `returned_to_lobby` / `left_lobby` 时清掉冷却记录,对端断线时清掉他的。

### 8.5 世界表现

- 抛:丢的人有酒客、活着、手空着(`can_throw`)时右手 0.16 s 往后上方蓄力(番茄握在爪里),再 0.1 s 甩向目标头,0.32 s 后手搭回桌上;
  期间有别的手臂动作接管(按 `_arm_serial` 判断)就交给它收尾。手被占着或出局时番茄直接从手里飞出;没有酒客时从吧台上方
  (`SPECTATOR_FROM = (-2.75, 1.5, -0.6)`)飞来。
- 飞:0.6 s 抛物线,顶点比连线高 0.15 + 0.08 × 距离(米),终点每帧按目标的头重新算(头在晃、在探也砸在同一处),转几圈。
- 落点:按种子在 4 个方向里挑(脸 50%、左腮 15%、右腮 15%、额头 20%)再抖一点,打在主颅骨椭球(`skull_ellipsoid()`,含动森式大头放大)
  的表面上。各端种子相同所以 Head 局部的落点相同(`test_same_seed_lands_on_the_same_spot_on_every_peer`)。
- 命中:`tomato_splat` 声、22 粒红色汁水(`Fx.juice_splash`,上限 24,复用柔和粒子着色器的普通混合版,不发光、不投影)、
  番茄泥挂在目标 Head 下(+Z 朝外法线、按种子转一个角度),弹一下贴上,5.1 s 后 0.9 s 内缩小并往下滑 3.5 cm 再释放,总共 6 s;
  同一个头最多 3 块,最旧的先摘。被砸的活人:吓一跳 + 眯眼(joy)皱眉(angry)+ 左右摇两下头 + 吐舌头,手空着时左爪抹两下脸;
  举着枪、正在庆祝时只吓一跳;出局的只贴泥、不反应。
- 网格:`banter:tomato`(红扁球 + 五片萼片 + 蒂)、`banter:splat`(平滑并集的扁片:中间一坨加六个溅瓣,亮色果肉块、六粒籽、一片卷起的皮;
  整体放大 1.7 倍,泥要糊住半张脸才好笑),都走 MeshForge 缓存 + `WorldMaterials.prop()`,`SHADOW_OFF`。静止状态下一个也不多
  (番茄砸完、泥 6 s 后都释放;`test_splat_is_released_after_about_six_seconds` 核对酒客可见网格数回到原值)。
- 说话:`BanterFx.say(pid, 编号, 物种兜底)` 取 `AnimalVoice.phrase_layout`,酒客按音节时刻点头(每个音节 0.04 s 低下 0.075 rad、0.07 s 抬回),
  `voice_enabled` 时从说话人 Head 上的 AudioStreamPlayer3D(`Voice`,SFX 总线,-2 dB,max +3 dB,unit_size 6;第一次说话时建,跟着酒客释放)播出。
  `voice_enabled` 由 BanterView 每帧按 `Sfx.muted` 设,无头时为假:不出声、不预热,时间表和点头照走。
  BanterFx 每秒看一眼桌上的酒客,把每个 (物种, 偏移档) 的 8 句投到工作线程预热(静音时不预热)。
- BanterFx 和 CardTable 一样不直接引用 Sfx 自动加载(tools/ 下 `-s` 启动的脚本编译时还没有自动加载):音效经 `sfx` 信号交给 main 播放。

### 8.6 气泡

- 挂点:说话人有铭牌(牌桌 `plate:%d`、等待厅 `lobby:%d`)就用铭牌的同一个锚点(`WorldLabels.anchor_of`)——德州铭牌按座位错开高度,
  气泡跟着错开;没有铭牌的自己挂在头顶(`Patron.speech_anchor()`:头心上方 0.34 m),比别人的小一点(0.85 倍);都绑定在酒客自己的方法上,
  酒客被换掉(复活、换形象)后 Callable 失效,WorldLabels 自动藏起。没有酒客的人(德州观战、迟到)改成一条提示条「名字:文案」,声音从吧台方向来。
- 偏移每帧现算:往上让开铭牌高度和牌桌上的声称 /「骗子!」气泡(`bubble:%d`)再加小三角;上面没地方了(铭牌贴着画面上缘——
  骗子酒馆越肩机位下对面的人常这样)就挪到铭牌 / 声称气泡旁边、朝画面中间那一侧,底边对齐,不叠在它们身上。
- 逐字:`Label.visible_characters` 按 `layout()["reveal"]` 的时刻推进(按整句排版,出字时大小不跳),声音结束后停 2.5 s,0.35 s 淡出自毁;
  同一个人新说一句,`labels.track` 同一个键顶掉旧的。奶油色(0.99, 0.95, 0.86)圆角 18、棕色描边、22 号展示字体,和声称气泡(羊皮纸色)区分开。
- 已知:德州 HUD 的左上信息框、右上按钮与气泡在同一层且画在后面,左上角那位的气泡会被信息框压住一部分——和他的铭牌一样
  (这是现有铭牌层的行为,没有改)。

### 8.7 叫声合成参数

22050 Hz、16 位。每个字一个音节(汉字、字母、数字);标点按码位给停顿(,0.12 s、、0.1 s、。0.14 s、!?0.06 s、… 0.22 s、~ 0.06 s、空格 0.08 s)。
音高 = 物种 f0 × 偏移档(5 档,0.93–1.07,`posmod(hash(pid), 5)`)× (1 ± 0.08 按「物种 + 字 + 位置」哈希)× 句内缓降 6%(问句不降);
音节时长 = 物种 syl × (0.9–1.1 哈希)。句尾音节:

| 句尾 | 时长 | 整体音高 | 句尾 / 句首音高 | 音量 | 其他 |
