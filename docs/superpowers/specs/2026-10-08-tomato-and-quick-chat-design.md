# 丢番茄与快捷语(动物叫声说话)设计(2026-10-08 用户追加)

> 用户原话:「先加一个丢番茄的功能吧,还有说话的功能,不同动物有不同的声音,说话的声音就是对应动物的叫声」。
> 用户已定:丢番茄谁都能随时丢;说话只用快捷语(不打字);叫声程序合成(和现有音效一样不加音频文件)。

## 1. 玩法

### 1.1 丢番茄
- 谁能丢:等待厅和牌局里所有在房间的人,包括在场的、出局的和观战的;骗子酒馆和德州都能用。
- 丢给谁:任意一位**有酒客的**玩家(不能丢自己;观战者没有酒客,不能被丢)。
- 冷却:每人 3 秒(`Banter.TOMATO_COOLDOWN`),房主为准;本机按钮或提示显示冷却。
- 纯搞笑,不影响胜负、不打断回合、不影响计时。
- 表现:
  - 丢的人有酒客时右手做一个抛的动作,番茄从手里飞出;没有酒客(观战)时从吧台方向的一个固定点飞来。
  - 番茄沿抛物线飞约 0.6 秒,落点是目标头部附近(按种子随机偏一点:脸、帽子、肩膀)。
  - 命中:「啪叽」声、红色汁水溅开(少量粒子)、一块番茄泥贴在命中处约 6 秒后淡出;同一个头最多叠 3 块,最旧的先没。
  - 被砸的人:吓一跳(`startle`)加抹脸或嫌弃的表情;出局的酒客也会被砸(泥贴在歪着的头上,不做反应)。

### 1.2 快捷语
- 8 句预设(编号 0–7,协议里只传编号):
  - 0「你骗人!」
  - 1「我信你。」
  - 2「这把稳了~」
  - 3「救命啊!」
  - 4「哈哈哈哈!」
  - 5「快点啦…」
  - 6「好牌!」
  - 7「呜呜呜…」
  - 文案可在实现时微调,两种玩法都要说得通。
- 说话频率:每人至少隔 1.5 秒(`Banter.SAY_COOLDOWN`),房主为准。
- 表现:
  - 说话人的头顶冒出对话气泡,文字跟着声音一个字一个字出现,说完停 2.5 秒后淡出。
  - 说话时头随每个音节轻点一下。
  - 声音从说话人的头部位置发出(3D 定位)。

## 2. 操作

- **T 键或鼠标右键**:丢番茄,目标是屏幕上离鼠标光标最近的酒客头部(投影距离 ≤140 px,不含自己);
  没有合格目标时提示「把光标移到要砸的人身上」。
- **Q 键**:打开快捷语面板,显示 8 句带编号的话。
  - 面板打开时按 1–8 或点击说出,Q 或 Esc 关闭;面板打开时数字键只给面板用,不再选牌或下注。
  - 说完自动关上。
- 这几个键都不在现有占用里:1–5、回车、C、空格、F、R、↑↓、WASD、说明书快捷键、Esc。
- 说明书和桌面提示补上「T 丢番茄 · Q 快捷语」。

## 3. 网络

- 不新增 autoload(不改 project.godot):`NetworkManager._ready()` 里加一个子节点 `Banter`(`src/net/banter_net.gd`),
  所有端路径一致为 /root/Net/Banter,RPC 都放在它身上,不影响 NetworkManager 的 RPC 表(`test_net_rpc_order` 不变)。
- 消息(都走 reliable):
  - `rpc_tomato(target_pid)`:客户端 → 房主。房主校验:发送者在名单里、目标在名单里且有酒客、不是自己、过了冷却;
    通过后生成种子,向全员(含房主本机)广播 `rpc_tomato_thrown(from_pid, target_pid, seed)`。
  - `rpc_say(phrase_id)`:客户端 → 房主。校验:0 ≤ id < 8、过了冷却;广播 `rpc_said(pid, phrase_id)`。
  - 房主本机操作直接走同一套校验和广播。不合法的消息静默丢弃(必要时 push_warning)。
- 协议号仍是 v5:0.7.0 尚未发布,和德州共用 v5;德州分支合并时会在 network_manager.gd 的 `_ready` 附近有一处小冲突。
- 等待厅和牌局都可用;回到等待厅、离开房间时清掉冷却记录。

## 4. 叫声合成(动森式「动物话」)

- 新文件 `src/audio/animal_voice.gd`(class AnimalVoice):按物种参数合成一个音节,把一句话逐字拼起来,得到一个 AudioStreamWAV。
  - 每个字(汉字、字母、数字)一个音节,约 70–95 ms;标点是短停顿;「!」末尾音量和音高抬起,「?」句尾上扬,「…」拖长、音高下沉。
  - 音高:物种基准音高 × 按字的哈希给的小起伏(同一句话每次念起来一样)× 本人一点随机偏移(按 pid 定,同一物种的两个人略有不同)。
  - 合成结果按 (物种, 句子编号, 音高偏移档) 缓存;启动后空闲时预热。
- 8 种叫声的合成思路(实现时可调,目标是一听就分得出来,卡通、不刺耳):

  | 物种 | 叫声 |
  |---|---|
  | 狐狸 | 高音短促的「嘤/呀」:带一点噪声的上滑锯齿波,共振峰偏高 |
  | 熊 | 低沉的「呜噢」:低频方波加次谐波,慢起慢收,带一点喉音颤 |
  | 猪 | 「哼哼」:鼻音,低中频脉冲串,每个音节两下快速的喉部脉冲 |
  | 猫 | 「喵」:元音从 i 滑到 a 再到 u 的共振峰滑动,中高音 |
  | 乌龟 | 慢吞吞的「咕噜」:很低的正弦加轻微气泡调制,音节拉长到约 1.4 倍 |
  | 羊驼 | 「嗯~」:哼鸣,带鼻腔共振的正弦加颤音,音高中等偏高 |
  | 猴子 | 「呜哇/吱」:快速上下滑的高音,音节短,偶尔夹一个更高的「吱」 |
  | 鳄鱼 | 低沉的「嘶咕」:噪声嘶声开头,接很低的咕噜,带一点颗粒感 |

- 播放:AudioStreamPlayer3D 挂在说话人头部,走 SFX 总线,遵守 `Sfx.muted`;无头运行时不出声但流程照走(测试可用)。

## 5. 世界与界面

- 世界(TableWorld 或新的 `src/world/banter_fx.gd`):`throw_tomato(from_pid, target_pid, seed)`、`say(pid, phrase_id)`。
  - 番茄、番茄泥网格用 MeshForge 缓存(番茄:红色扁球、绿色蒂;泥:不规则扁片),材质用 WorldMaterials 现有的道具材质;
    小件不投影;番茄泥挂在目标的 Head 下,用完释放。
  - 番茄泥不能让静止状态下的酒客可见网格超过 16 个(只在命中后的几秒内存在,测试按静止状态测)。
  - 汁水粒子复用现有粒子材质;一次 ≤24 粒。
- 酒客:`Patron.hit_by_tomato(local_point)` 触发反应;说话的点头放在 PatronAntics 里(`talk(syllable_times)`)。
- 气泡:用现有的 WorldLabels(名牌挂点那一套)挂在头顶名牌之上,UiTheme 风格的圆角气泡;
  同一个人新说一句就替换旧气泡;不挡自己的手牌(气泡高于名牌,本机自己的气泡可以略小)。
- 音效:Sfx 加「tomato_throw」(短 whoosh)与「tomato_splat」(湿的啪叽:低频冲击加滤波噪声的湿尾巴)。

## 6. 约束

- 不改 project.godot、不改协议号;不在 src/ 里运行时读网格数组;不 duplicate ShaderMaterial;新静态缓存在 main.gd `_exit_tree` 释放。
- 性能:同时飞 8 个番茄、贴 8 块泥时 seat 视角 draw call 增量 ≤ 30,帧时间无明显变化;perf_probe 预算照过。
- 联机冒烟 `tools/lan_smoke.sh` 照过;可选:冒烟里加一次互丢番茄和说话,核对各端都收到。

## 7. 测试

- 协议与校验(无头):冷却、非法 id、丢自己、丢观战者、发送者不在名单,都被房主拒绝;合法的广播给全员且种子一致。
- 叫声:同一 (物种, 句子, 偏移) 两次合成逐样本相同;8 个物种的基频或频谱质心互不相同;「!」和「?」句尾的音高变化方向正确;
  每句时长在 0.4–2.5 秒之间。
- 世界:番茄落点在目标头附近;命中后泥挂在目标 Head 下、6 秒后释放;同一个头最多 3 块;出局的酒客被砸不报错。
- 界面:Q 面板打开时数字键不再选牌或下注;T 选目标的屏幕投影规则;冷却期间不发消息。
