# 骗子酒馆(Liar's Tavern)

局域网 2–4 人 3D 吹牛出牌游戏。轮流盖牌声称是本局目标牌,被抓到说谎或质疑失败,就得拿起左轮对自己扣一次扳机——活到最后的人赢。

- 3D 酒馆:烛火、壁炉、月光、体积光;卡通动物酒客会眨眼、看向当前行动者、拍桌、举枪、中弹倒下
- 第三人称越肩视角:你的角色也坐在桌边,手牌举在胸前、牌面朝向你;开枪时镜头转到开枪者正面特写
- 全部美术与音效程序化生成,无外部资源
- 局域网联机:房主开房,其他人在房间列表里自动看到;也可以输入 IP 直连

## 运行

1. 安装 [Godot 4.7](https://godotengine.org/)(macOS:`brew install --cask godot`)
2. 在仓库根目录运行:`godot --path .`(或用编辑器打开项目后按 F5)
3. 导出桌面包:编辑器 → 项目 → 导出(Windows / macOS 预设)

## 联机

1. 一位玩家填好名号,点「开设房间」,进入等待厅。等待厅会显示房主的局域网地址,可点「复制」。
2. 同一局域网的其他玩家打开游戏,主菜单「局域网房间」列表会自动出现该房间,点「加入」;
   看不到时,在「IP 直连」输入房主地址(`192.168.x.x`,非默认端口时写 `192.168.x.x:端口`)。
3. 客人点「准备」,2–4 人全员准备后房主点「开始游戏」。

网络说明:

| 用途 | 协议/端口 |
|---|---|
| 房间发现(广播) | UDP 47800–47803 |
| 游戏通信(ENet) | UDP 47810(被占用时顺延到 47811–47819) |

- 首次运行时系统防火墙若询问是否允许 Godot 接收连接,请选择允许。
- 同一台电脑可以开多个实例测试:最多 4 个实例都能在列表中发现房间,也可以直连 `127.0.0.1`。
- 游戏中断线即出局;房主退出则房间解散。

## 操作

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 选牌(1–3 张) | 点击手牌 | `1`–`5` |
| 出牌 | 「出牌」按钮 | `Enter` |
| 质疑上家 | 「质疑!」按钮 | `C` / `空格` |
| 翻开说明书 | 「规则」/「游戏规则」按钮 | `F1` |
| 离开 / 合上说明书 | — | `Esc` |

不是自己回合时也可以先预选手牌。

## 规则

游戏内随时可以翻开说明书「酒馆规矩」:主菜单「游戏规则」、等待厅「规则」、牌桌右上角「规则」,或任意界面按 `F1`。
看说明书时对局不会暂停;轮到你时会弹出提示。

- 牌堆 20 张:Q / K / A 各 6 张 + 鬼牌 2 张(万能牌,视同任何目标牌)。
- 每局随机抽一种目标牌(桌心立牌显示),每位存活玩家发 5 张。
- 轮到你时二选一:盖着打出 1–3 张并声称全是目标牌(可以说谎),或者质疑上家。
- 质疑时翻开上家那组牌:全是目标牌/鬼牌 → 质疑者开枪;有一张不是 → 出牌者开枪。
- 每人一把六膛左轮,整场只装一发子弹;每次空枪后弹巢前进一格,越往后越危险,第 6 枪必中。
- 只剩一个人有手牌时,他出的牌会被系统强制翻开验证。
- 每次开枪后重新发牌开始新的一局。最后活着的人获胜。
- 回合限时 30 秒(加上动画时间),超时会自动替你打出第一张牌。

完整规格见 [docs/superpowers/specs/2026-08-14-liars-tavern-design.md](docs/superpowers/specs/2026-08-14-liars-tavern-design.md)。

## 开发

```bash
export GODOT=/Applications/Godot.app/Contents/MacOS/Godot

# 单元测试(GUT)
$GODOT --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit

# 联机冒烟:1 房主 + 2 个 bot(一个走局域网发现、一个直连),无头跑完整局
tools/lan_smoke.sh

# 截图检查(需要窗口):搭好酒馆并按机位截图
$GODOT --path . -s tools/shot.gd -- --out=/tmp/shots --views=seat,menu --showcase
```

调试命令行开关(写在 `--` 之后):`--name=甲`、`--autohost[=人数]`、`--autojoin=IP`、`--discover`、
`--bot`、`--fast[=倍率]`、`--quit-after-match`、`--shots=目录`。

目录结构:

```text
src/core/    纯规则逻辑(状态机、牌堆、左轮、判定)——全部单测
src/net/     协议、视图、等待厅名单、房间发现、ENet 房主权威网络层
src/world/   3D 酒馆:场景、材质着色器、卡牌、左轮、酒客、相机、特效
src/ui/      主题、音效、主菜单、等待厅、说明书、牌桌(控制器/演出导演/HUD/结算)
tools/       联机探针、冒烟脚本、截图工具
tests/       GUT 单元测试
```
