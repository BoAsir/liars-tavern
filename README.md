# 骗子酒馆 (Liar's Tavern)

局域网 3D 酒馆桌游，开房时选玩法：

- **骗子酒馆**(2–4 人):吹牛出牌。轮流盖牌声称是本局目标牌，被抓到说谎或质疑失败，就得拿起左轮对自己扣一次扳机——活到最后的人赢。
- **德州扑克**(2–8 人，长牌 / 短牌):无限注现金局。入座领 2000 筹码、盲注 10/20,输光可以再领;开打后新玩家可以中途入座;
  房主随时散局，按盈亏排名结算。

- 3D 酒馆：烛火、壁炉、月光、体积光;卡通动物酒客会眨眼、看向当前行动者、拍桌、举枪、中弹倒下
- 第三人称越肩视角：你的角色也坐在桌边，手牌举在右肩旁、牌面朝向你;开枪时镜头转到开枪者正面特写
- 全部美术与音效程序化生成，无外部资源
- 局域网联机：房主开房，其他人在房间列表里自动看到;也可以输入 IP 直连

## 下载

到 [Releases](https://github.com/Murphycx94/liars-tavern/releases) 下载最新安装包：

- **macOS**(Intel 与 Apple 芯片通用):`LiarsTavern-<版本>-macOS.zip`,用访达双击解压得到 `骗子酒馆.app`。
  安装包没有经过苹果公证，第一次打开会被系统拦下：到「系统设置 → 隐私与安全性」底部点「仍要打开」
  (macOS 14 及更早也可以右键点 App 选「打开」)。macOS 15 及以上第一次开房、搜索或加入房间时会询问「本地网络」权限，请选允许。
- **Windows**(64 位):`LiarsTavern-<版本>-Windows.zip`,解压后运行文件夹里的 `骗子酒馆.exe`(exe 与同目录的 `.pck` 要放在一起)。
  程序没有数字签名，出现「Windows 已保护你的电脑」时点「更多信息」→「仍要运行」;开着「智能应用控制」的 Windows 11
  会直接拦下未签名程序，需要先关掉它。防火墙询问时请允许，当前网络是「公用网络」时也要勾上，或者把网络改成「专用网络」。
  文件属性、防火墙提示里显示的名字是「Godot Engine」,这是引擎的默认信息，不影响游戏。
- 附带的 `SHA256SUMS.txt` 是两个安装包的 SHA-256 校验值。

## 在线更新

装好一次之后，游戏会自己更新，不用再下载安装包：

- **网上**:启动时自动检查本仓库 `updates` 分支上的新版本，有的话主菜单顶部出现提示，点「更新」再「重启」即可。
  新版本发布后约 5 分钟内能查到 (GitHub 的缓存);国内连不上 GitHub 时会安静地跳过，不影响游戏。
- **局域网**:房主是新版本、而且和你是同一个系统 (Mac 对 Mac、Windows 对 Windows) 时，房间列表里他的房间旁会有
  「更新」按钮 (版本差到不能同桌时显示「更新后加入」),点了从房主那里下载，下载完点「重启」生效。没网也能更新。
- 每次更新只下载几百 KB 的游戏内容包;更新包都有发布者的签名，游戏只接受签名正确的包。
- 引擎升级或改了项目设置的版本没法在线更新，提示条会说明需要下载完整安装包。
- 更新后的版本连续两次没能正常启动，会自动退回安装包自带的版本。要手动退回，用启动参数启动一次：
  macOS 在终端运行 `open 骗子酒馆.app --args -- --no-update`,Windows 在命令行运行 `骗子酒馆.exe -- --no-update`。
  之后正常启动就好;下次有新版本时照常更新。

## 从源码运行

1. 安装 [Godot 4.7](https://godotengine.org/)(macOS:`brew install --cask godot`)
2. 在仓库根目录运行：`godot --path .`(或用编辑器打开项目后按 F5)

## 联机

1. 一位玩家填好名号，选好玩法 (骗子酒馆 / 德州扑克·长牌 / 德州扑克·短牌),点「开设房间」,进入等待厅。
   等待厅会显示房主的局域网地址，可点「复制」。玩法开房后不能改，想换玩法就重新开一桌。
2. 同一局域网的其他玩家打开游戏，主菜单「局域网房间」列表会自动出现该房间，点「加入」;
   看不到时，在「IP 直连」输入房主地址 (`192.168.x.x`,非默认端口时写 `192.168.x.x:端口`)。
3. 客人点「准备」,全员准备后房主点「开始游戏」(骗子酒馆 2–4 人，德州扑克 2–8 人)。
4. 德州扑克开打后，房间列表里那一桌显示「入座」:新玩家可以直接加入，旁观完当前这一手，下一手开始发牌。

网络说明：

| 用途 | 协议/端口 |
|---|---|
| 房间发现 (广播) | UDP 47800–47803 |
| 游戏通信 (ENet) | UDP 47810(被占用时顺延到 47811–47819) |
| 局域网更新 (房主提供的下载) | TCP，端口号与游戏通信相同 |

- 首次运行时系统防火墙若询问是否允许 Godot 接收连接，请选择允许。
- macOS 15 及以上还有「本地网络」权限：从 Godot 编辑器或导出的 .app 启动后，第一次在局域网收发数据
  (开房、搜索或加入房间) 时系统会询问，请选择允许;之前拒绝过的话，到「系统设置 → 隐私与安全性 → 本地网络」
  里打开本游戏 (或 Godot) 后重开游戏。未授权时局域网收发会失败。
- 房主的房间广播连续几秒都发不出去时 (没授权本地网络、网卡/路由异常等),等待厅会出现红字提示：
  其他人可能在房间列表里看不到这桌，请把等待厅显示的地址告诉他们用「IP 直连」。
- 同一台电脑可以开多个实例测试：最多 4 个实例都能在列表中发现房间，也可以直连 `127.0.0.1`。
- 游戏中断线即出局 (德州扑克里等于离桌：这一手按弃牌处理，已全下的照常摊牌);房主退出则房间解散。

## 规则

游戏内随时可以翻开说明书「酒馆规矩」:主菜单「游戏规则」、等待厅「规则」、牌桌右上角「规则」,或任意界面按 `F1`。
说明书分骗子酒馆、德州扑克两本，顶部页签切换;默认翻到当前玩法那本 (主菜单上是上次选的玩法),每本记得上次读到哪一章。
看说明书时对局不会暂停;轮到你时会弹出提示。

### 骗子酒馆

- 牌堆 20 张:Q / K / A 各 6 张 + 鬼牌 2 张 (万能牌，视同任何目标牌)。
- 每局随机抽一种目标牌 (桌心立牌显示),每位存活玩家发 5 张。
- 轮到你时二选一：盖着打出 1–3 张并声称全是目标牌 (可以说谎),或者质疑上家。
- 质疑时翻开上家那组牌：全是目标牌/鬼牌 → 质疑者开枪;有一张不是 → 出牌者开枪。
- 每人一把五膛左轮，整场只装一发子弹;每次空枪后弹巢前进一格，越往后越危险，第 5 枪必中。
- 只剩一个人有手牌时，他出的牌会被系统强制翻开验证。
- 每次开枪后重新发牌开始新的一局。最后活着的人获胜。
- 回合限时 30 秒 (加上动画时间),超时会自动替你打出第一张牌。

完整规格见 [docs/superpowers/specs/2026-08-14-liars-tavern-design.md](docs/superpowers/specs/2026-08-14-liars-tavern-design.md)。

### 德州扑克

- **长牌**用 52 张;**短牌**去掉 2–5,共 36 张。短牌里同花比葫芦大，其余牌型大小与长牌相同;
  A 可以当最小牌接顺子 (长牌 A-2-3-4-5,短牌 A-6-7-8-9)。
- 无限注现金局:2–8 人，入座领 2000 筹码，盲注 10/20 固定不升，所有金额都是 10 的倍数。
- 每手 2 张手牌 + 5 张公共牌，取最大的 5 张;边池、未跟注部分退回、不完整加注不重开行动，都按通行规则 (说明书里有详细说明)。
- 输光后可以「再领 2000」(不限次数)或「观战」;观战中随时可以领筹码，下一手上桌。
- 回合限时 30 秒 (加上动画时间),超时能过牌就过牌，否则弃牌;连续 2 次超时从下一手起离座，点「回到牌桌」回来。
- 房主点「散局」:打完当前这一手后结算，盈亏 = 筹码 − 领取次数 × 2000,所有人盈亏之和为 0;结算后房主可以带大家回等待厅。
- 公共牌、摊牌在画面上另有 2D 大图;界面左下是自己的手牌和当前最大牌型。

完整规格见 [docs/superpowers/specs/2026-10-07-texas-holdem-design.md](docs/superpowers/specs/2026-10-07-texas-holdem-design.md)。

## 开发

```bash
export GODOT=/Applications/Godot.app/Contents/MacOS/Godot

# 单元测试(GUT)
$GODOT --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit

# 联机冒烟:1 房主 + 2 个 bot(一个走局域网发现、一个直连),无头跑完整局
tools/lan_smoke.sh

# 德州联机冒烟:1 房主 + 3 个 bot(第 4 个在第 1 手开始后才走局域网发现加入),打 6 手后散局;
# 检查全部正常退出、迟到者上过桌、盈亏之和为 0、视线同步走通
MODE=holdem tools/poker_smoke.sh
MODE=short_deck tools/poker_smoke.sh

# 截图检查(需要窗口):搭好酒馆并按机位截图
$GODOT --path . -s tools/shot.gd -- --out=/tmp/shots --views=seat,menu --showcase

# 德州离线展台(需要窗口):8 位酒客、公共牌、筹码与假数据喂的 HUD;4:3 在 -s 前加 --resolution 1280x960
$GODOT --path . -s tools/shot.gd -- --out=/tmp/shots --views=poker_seat,poker_overview \
  --hud=bet,spectate --poker-showcase

# 德州真机 8 人截图:1 个有窗口的房主 + 7 个无头直连 bot
$GODOT --path . -- --autohost=8 --mode=holdem --bot --shots=/tmp/shots --hands=3 --quit-after-match --port=47810 &
sleep 2
for i in 1 2 3 4 5 6 7; do
  $GODOT --headless --path . -- --autojoin=127.0.0.1:47810 --bot --name=bot$i --quit-after-match &
done
wait
```

调试命令行开关 (写在 `--` 之后):`--name=甲`、`--autohost[=人数]`、`--mode=liars|holdem|short_deck`(配合 `--autohost`)、
`--hands=N`(德州房主：第 N 手开始时散局)、`--port=端口`、`--room=房名`、`--autojoin=IP[:端口]`、`--discover[=房名]`、
`--bot`(德州按合法动作随机下注、输光再领;带 `--shots` 时第一次输光先观战)、`--fast[=倍率]`、`--quit-after-match`、
`--shots=目录`(德州截图：发牌、翻牌、轮到自己、全下、摊牌、分池、观战、结算)、`--update-from=IP:端口`、`--update-url=网址`。

每台机器只有 4 个发现端口 (UDP 47800–47803),同机最多 4 个实例能用局域网发现;更多实例 (如 8 人截图) 用 `--autojoin` 直连。

### 发布新版本

需要 [导出模板](https://godotengine.org/download)(与引擎版本一致) 和更新签名私钥
(`~/.config/liarstavern/update_signing_key.pem`,不在仓库里;第一次用 `tools/make_update_key.gd` 生成，务必备份)。

1. 把 `build.json` 的 `build` 加一、改好 `version`;改过 `project.godot` 时把 `base_build` 也设成同一个数 (必须重装)。
2. 提交并推送到 `main`,然后 `tools/release.sh "这次更新了什么"`:在当前提交的临时干净副本里导出两个平台的安装包、
   签好更新包，产物放在主仓库的 `build/`(工作区里没提交的改动不会进包;全部成功才替换旧产物)。
3. `tools/publish_update.sh`:核对无误后把更新包推到 `updates` 分支，已安装的游戏约 5 分钟后启动就能更新。推出去撤不回。
4. `tools/publish_release.sh [发布说明.md]`:把安装包发成 GitHub Release(需要 `gh auth login`),给新玩家下载;
   tag 打在导出用的那个提交上，附件用英文文件名并附校验值，发布后会从公开地址下载回来核对;可以重复运行。

目录结构：

```text

src/net/     协议、视图、等待厅名单、房间发现、ENet 房主权威网络层
src/world/   3D 酒馆：场景、材质着色器、卡牌、左轮、酒客、相机、特效
src/ui/      主题、音效、主菜单、等待厅、说明书、牌桌 (控制器/演出导演/HUD/结算)
src/update/  在线更新：启动引导、签名清单、下载、局域网文件服务
tools/       联机探针、冒烟脚本、截图工具、发布与签名脚本
tests/       GUT 单元测试
```
